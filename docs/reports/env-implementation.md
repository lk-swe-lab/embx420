## Contract

`env [--json] [-h|--help]`, no operands; `--` alone accepted. Unique option
abbreviations accepted by Argtable; duplicate flags invalid; invalid arguments
override help. Module validates argc/argv and every argument pointer first,
copies argv before parsing, restores exported getopt state, uses invocation-owned
Argtable entries for parser/help. Registry publishes the shared specification;
standalone delegates to the same run function.

Nonempty arbitrary-byte key, first `=` split; value may be empty or contain `=`.
Missing `=`/empty key fails1 before output in either mode. All original entries
(including ignored duplicates) are validated. Keys sorted unsigned-byte
lexicographically; equal keys sorted by original position, first value retained.
Raw emits KEY=VALUE LF preserving arbitrary bytes, so embedded LF is ambiguous.
JSON emits one `{"env":{...}}` LF record, UTF-8 scalars preserved; controls,
quotes/backslashes escaped. Invalid UTF-8 anywhere fails1 before JSON output.
NULL/empty environ means zero entries: empty raw / `{"env":{}}` LF JSON.
No NUL inside environ C strings. No shell-identifier restriction.

Owned metadata is O(n), sorting O(nlogn), no fixed entry/byte limit besides memory.
Borrow strings/vector for the call; caller must provide stable valid C storage,
no concurrent mutation. No assignments, execution, unset, cwd/signal changes,
or reads from stdin. Preserve environ/vector/string bytes and pointer identities,
argv pointer order/strings, exported optarg/optind/opterr/optopt and descriptors.
No promise for getopt private interrupted-scan state or thread safety.

Constructor NULL/module-owned allocation failures produce1/stderr/no output,
release all prior owned allocations. Internal Argtable OOM can terminate host
(confirmed probe exits1 with `Out of memory!`); not recoverable module allocation.
Shared lines_write retriesEINTR and short writes; zero write becomesEIO. Output
failure returns1, can leave partial output. Help detects fflush/ferror and clears
its stream error for later reuse. Empty raw writes nothing and cannot detect
bad stdout. Host brokenpipe signal policy remains inherited; no rollback after
output. The void usage callback cannot report allocation failure as an exit
status; `env --help` run can. Real `main help env` output/help parity verified.
