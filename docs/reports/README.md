# Historical command reports

These are byte-preserved snapshots of the original command inventories, plans,
verification evidence and independent review. Status statements and paths reflect
when each report was written; historical links may no longer resolve here.
Do not treat an old plan or pending status as current command availability.

Current usage: [README command index](../../README.md#supported-commands) and
`docs/commands/<command>.md`. Coordination records now live under `.tmp/`;
`mkdir-review.md` is in this directory. No report evidence was rewritten.
